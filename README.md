# English Yut Battle — 2차 버전

초등 6학년 영어 수업용 실시간 윷놀이 대결 게임입니다. 한 방에 2~5명, 한 반 30명이면 6개 방을 동시에 운영합니다.

## 실행하기

1. Node.js 20 이상을 설치합니다.
2. 이 폴더에서 `npm install`
3. 교사 PIN을 정해 실행합니다.
   - Windows PowerShell: `$env:TEACHER_PIN='내비밀번호'; npm start`
   - macOS / Linux: `TEACHER_PIN=내비밀번호 npm start`
4. 교사 컴퓨터 브라우저에서 `http://localhost:3000`
5. 학생 태블릿은 **같은 와이파이**에 연결한 뒤 `http://교사컴퓨터IP:3000`
   (윈도우 방화벽에서 3000 포트 허용이 필요할 수 있습니다.)

> PIN을 정하지 않으면 `2468`이 쓰입니다. 수업 전에 꼭 바꾸세요.

## 1차 버전에서 고친 것

| | 1차 시제품 | 2차 버전 |
|---|---|---|
| 엑셀 업로드 | 제공된 템플릿이 **0문제로 거부됨** (열 이름 불일치) | 한글·영어 열 이름 모두 인식, 난이도·해설까지 사용 |
| 윷 확률 | 개 25% / 윷 18.7%, 한 번 더 25% | 윷가락 4개를 각각 던져 **실제 확률** (개 37.5% / 윷 6.25%, 한 번 더 12.5%) |
| 지름길 | 모서리를 **지나가기만 해도** 빨려 들어감 | 모서리에 **정확히 멈췄을 때만**. 방(중앙)에 멈추면 도착 지름길로 |
| 업기 | 글자만 찍히고 실제로는 따로 움직임 | 같은 칸의 내 말이 **함께 이동**, 함께 잡힘 |
| 영어 문제 | 방 전체 공용 카운터 → 학생 간 **최대 1문제 vs 19문제** | 전원이 함께 푸는 배틀 → **차이 3~7문제** |
| 턴 제한 | 없음 (한 명이 멈추면 전원 대기) | 턴 40초, 문제 15초, 잡기 12초 · **계속 버튼으로 즉시 진행** |
| 끊긴 학생 | 그 차례에서 전원이 60초 대기 | 자동으로 건너뜀 + 방장이 넘기기 가능 |
| 서버 재시작 | 모든 방이 사라짐 | 4초마다 저장, 재시작 시 자동 복구 |

## 경쟁 대결 (2차에서 새로 넣은 것)

**영어 배틀** — 차례가 시작되면 방의 **모든 학생에게 같은 문제**가 동시에 뜹니다.
- 던지는 학생이 맞히면 증강 3개 중 하나를 고릅니다.
- 가장 빨리 맞힌 학생에게는 보너스 증강을 줍니다.
- 정답 순서대로 ⚡속도 점수(3·2·1점)가 쌓입니다.
- 기다리는 시간이 통째로 영어 연습 시간이 됩니다.

**잡기 승부** — 상대 말에 올라서면 바로 잡지 않고, 두 사람에게만 문제를 냅니다.
- 공격한 쪽이 이기면 잡고 한 번 더 던집니다.
- 수비한 쪽이 이기면 막아내고, 공격한 말은 원래 자리로 되돌아갑니다.
- 둘 다 맞히면 더 빨리 답한 쪽이 이깁니다.

**역전 보정** — 뒤처진 학생일수록 희귀·전설 증강이 나올 확률이 올라갑니다.

**기다리지 않습니다** — 정답이 공개되면 **계속 ▶** 버튼이 나오고, 누구나 눌러 바로 넘어갑니다.
아무도 안 누르면 6초 뒤 자동으로 넘어갑니다. 아직 답을 안 낸 친구가 있으면
방장에게 **⏩ 기다리지 않고 바로 채점** 버튼이 나옵니다.

**멈춘 친구를 건너뜁니다** — 태블릿이 꺼지거나 창을 닫은 학생의 차례는 자동으로 건너뜁니다.
방장에게는 **⏭️ ○○ 차례 넘기기** 버튼도 있어 언제든 넘길 수 있습니다.
(1차 버전에서 "내 차례가 아닙니다"만 뜨고 60초를 기다리던 문제가 이것이었습니다.)

**증강 13종** — 이동(질주·도약·부활·두 배 이동·다시 던지기·운명의 윷), 공격(얼음 감옥·역행·함정·능력 훔치기), 수비(방어막·전체 보호·순간이동). 일반·희귀·전설 등급.

## 디자인

- 도·개·걸·윷·모를 **돼지(pig)·개(dog)·양(sheep)·소(cow)·말(horse)** 로 보여 줍니다.
  윷을 던질 때마다 동물이 튀어나오며 `A sheep! Move 3 spaces.` 가 함께 나옵니다.
- 한지 색 바탕에 단청 색을 쓴 전통 느낌, 둥근 글꼴(Jua).
- 윷가락 4개가 구르는 애니메이션, 말이 한 칸씩 뛰어가는 애니메이션, 증강 발동 컷인.
- 학생마다 동물 아바타(🐰🐻🐱🦊🐼)를 받고, 말에도 그 동물이 표시됩니다.
- 태블릿 세로·가로, 휴대폰까지 한 화면에 들어갑니다.

> 글꼴은 Google Fonts에서 받아옵니다. 학교 네트워크가 외부를 막아 두었다면
> 기본 글꼴로 보일 뿐 게임은 그대로 작동합니다.

## 수업 링크 — 주소 하나로 반 전체

문제를 넣어 **수업**을 만들면 주소가 하나 나옵니다. 그 주소를 반 전체에 알려 주면
학생들이 들어가 **모둠별로 방을 만들어** 게임합니다. 모든 모둠이 같은 문제로 풉니다.

1. 관제실 **① 수업 만들기**에서 수업 이름을 쓰고 문제 엑셀을 고릅니다.
2. **수업 만들기**를 누르면 `https://내주소/?class=AB12` 같은 주소가 나옵니다.
3. **주소 복사**를 눌러 반 전체에 알려 줍니다. (칠판·TV·메신저 어디든)
4. 학생이 그 주소를 열면 위에 **📚 수업 이름**이 뜨고, 이름을 쓴 뒤
   모둠 대표가 **방 만들기**, 나머지는 그 **방 코드로 들어가기** 를 합니다.
5. 6개 모둠이면 방 6개가 생기고, 관제실에서 한눈에 봅니다.

엑셀을 안 넣고 만들면 지금 들어 있는 문제은행을 그대로 씁니다.

## 선생님 관제실

시작 화면 아래 **선생님용 관제실**을 열고 PIN을 넣으면 들어갑니다.

- 모든 방의 현재 차례, 진행 시간, 일시정지 여부
- 학생별 정답 수·정답률·보유 증강 개수·접속 상태
- 방 **관전 / 일시정지·재개 / 닫기**
- 문제은행 교체 — **모든 방** 또는 **특정 방에만** 적용

## 엑셀 문제은행

첫 행(열 제목)은 아래 둘 중 어느 쪽이든 됩니다.

```
unit   question   option1  option2  option3  option4  answer  level  explanation
단원명  영어 문제   선택지 1  선택지 2  선택지 3  선택지 4  정답 번호  난이도   해설
```

- `answer`(정답 번호)는 1~4입니다.
- `level`은 easy / medium / hard — 문제 위에 표시됩니다.
- `explanation`(해설)은 **채점이 끝난 뒤에만** 보입니다.
- 비거나 잘못된 줄은 건너뛰고, **몇 행에서 왜 건너뛰었는지** 알려 줍니다.
- 정답 번호는 채점 전까지 학생 화면으로 내려보내지 않습니다.

## 게임 모드

- **🌱 간편 수업** — 2턴마다 영어 배틀, 증강 8종. 20분 안팎.
- **🔥 본격 증강** — 매 턴 영어 배틀, 증강 13종 전부. 30분 이상.
- 말 개수는 2·3·4개 중에 고릅니다. **40분 한 차시라면 말 2~3개를 권합니다.**

## 인터넷에 올리기 (Render)

교사 컴퓨터를 켜 두지 않아도 되도록 Render에 올릴 수 있습니다. 이 폴더에 `render.yaml`이 들어 있어
Blueprint로 한 번에 만들어집니다.

1. 이 폴더를 **GitHub 저장소**로 올립니다. (`node_modules`와 `data`는 `.gitignore`로 빠집니다.)
2. [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
3. **New → Blueprint**를 고르고 그 저장소를 선택합니다. `render.yaml`을 읽어 설정이 채워집니다.
4. **TEACHER_PIN**을 물어보면 원하는 비밀번호를 넣습니다. (코드에는 적히지 않습니다.)
5. Apply를 누르면 몇 분 뒤 `https://이름.onrender.com` 주소가 나옵니다.
6. 학생들에게 그 주소를 알려 주면 끝입니다. 교사 컴퓨터도, 같은 와이파이도 필요 없습니다.

Blueprint 없이 손으로 만들려면 **New → Web Service**에서
Runtime `Node`, Build `npm install`, Start `npm start`, Health Check Path `/healthz`,
환경변수 `TEACHER_PIN`을 직접 넣으면 됩니다.

### 무료 플랜에서 꼭 알아야 할 두 가지

**① 15분 쉬면 잠듭니다.** 다시 깨어나는 데 약 1분이 걸립니다.
수업 **5분 전에 주소를 한 번 열어 두세요.** 그러면 학생들이 기다리지 않습니다.
수업 중에는 계속 쓰이므로 잠들지 않습니다.

**② 서버가 다시 시작되면 진행 중이던 방이 사라집니다.**
무료 플랜은 파일을 저장할 수 없어서, 서버가 알아서 저장 기능을 끄고 아래처럼 알려 줍니다.

```
저장을 끕니다 (디스크에 쓸 수 없는 환경)
게임은 그대로 작동합니다. 다만 서버가 다시 시작되면 진행 중이던 방이 사라집니다.
```

한 차시 안에는 문제가 없지만, 안심하려면 월 $7 플랜으로 올리면 잠들지도 않고
디스크(월 $0.25/GB)를 붙여 저장도 살아납니다. 유료로 바꾸려면 `render.yaml`의
`plan: free`를 `plan: starter`로 고치면 됩니다.

### 올린 뒤 확인

- `https://내주소.onrender.com/healthz` 를 열면 방 개수·접속 인원·저장 상태가 보입니다.
- 지역은 `singapore`로 해 두었습니다. 한국에서 가장 가깝습니다.
- 인터넷에 열려 있으므로 **TEACHER_PIN은 꼭 어렵게** 정하세요. 학생은 방 코드로만 들어옵니다.

## 아직 남은 것

- 백도(뒷도)는 넣지 않았습니다. 넣으려면 윷가락 하나에 표시를 더하면 됩니다.
- 교사 계정은 PIN 하나입니다. 교내망에서만 쓰세요.
- 인터넷에 공개하려면 HTTPS와 접근 제어가 더 필요합니다.
- 실제 갤럭시탭 여러 대로 하는 통합 시험은 아직 하지 않았습니다. 수업 전에 2~5대로 미리 해 보세요.
