# 증강 윷놀이 — English Yut Battle (3차 버전)

6학년 영어 수업용 실시간 윷놀이 게임입니다. 모둠끼리 방을 만들어 겨루고,
라운드마다 영어 문제를 함께 풀어 **증강**을 얻습니다.

## 3차 버전에서 달라진 것

### 1. 증강 71종
첨부해 주신 목록을 전부 넣었습니다. 초등 수업용이라 **'죽이다'는 모두 '잡다 ·
되돌려보내다 · 탈락'으로 바꿔 적었고**, 자극적인 이름 몇 개는 교실에서 쓸 수 있게
바꿨습니다.

| 원래 이름 | 바뀐 이름 | 이유 |
|---|---|---|
| 개돼지 | 한 걸음씩 | 비하 표현 |
| 마신 소환 | 합창단 소집 | 의식 코인 → 박수 |
| 나에게 윷놀이는 "살인"이다 | 끝까지 간다 | 체력 규칙은 그대로 |
| 카니발리즘 | 나를 희생해 | 규칙은 그대로 |
| 무신정변 | 연승왕 | 상대 말 4개 잡으면 승리 |
| 역모 | 따라잡기 | 규칙은 그대로 |
| 히히 똥! | 앗, 미끄러워! | 똥 → 진흙 웅덩이 |
| 독이 든 성배 | 위험한 선물 | 규칙은 그대로 |
| 네크로맨서 | 구조대 | 규칙은 그대로 |
| 프랜드 실드 | 친구 방패 | 우리말로 |
| 스겜 | 스피드 게임 | 줄임말 풀어 씀 |

나머지 60종은 이름과 규칙을 그대로 두었습니다.

**분류** — 이동 8 · 윷 9 · 공격 12 · 수비 5 · 이득 7 · 증강 조작 6 ·
특수 승리 4 · 시작 전용 8 · 중간 전용 4 · 마무리 전용 8
이 중 **15종이 특수 승리 조건**입니다(사목, 애묘인, 연승왕, 웅녀, 777 등).

**단계별 등장** — 1라운드엔 '시작 전용', 2~6라운드엔 '중간 전용',
7라운드부터 '마무리 전용'이 섞여 나옵니다.

### 2. 증강을 얻는 방법이 바뀌었습니다
라운드마다 이렇게 돕니다.

1. **영어 문제** — 방 안 모두가 동시에 답합니다.
2. **증강 선택** — 정답·오답과 상관없이 **모두가 3장 중 1장**을 고릅니다.
3. **정답자 보너스** — 맞힌 사람은 **한 장 더** 고릅니다.
4. 그다음 한 사람씩 윷을 던지고 말을 옮깁니다.

뒤처진 학생일수록 희귀·전설 증강이 나올 확률이 올라갑니다.

### 3. 새로 생긴 규칙
- **백도** — 윷가락 하나에 표시가 있습니다. 그 가락만 평평하면 뒤로 한 칸입니다.
  (확률은 전통 윷 그대로 — 백도 1/16, 도 3/16, 개 6/16, 걸 4/16, 윷 1/16, 모 1/16)
- **탈락** — 몇몇 증강은 사람을 탈락시킵니다. 마지막까지 남으면 승리합니다.
- **체력 · 개 코인 · 박수** — 증강에 따라 생기는 자원입니다.
- **말 종류** — 도깨비 · 선봉장 · 포 · 폰 · 김첨지 · 중전마마 · 마라토너 · 합창단원
- **판 위의 타일** — 진흙 🟤 · 함정 🕳️ · 보상 🎁 · 마늘 🧄
- **판 돌리기 · 접기 · 안개**
- **공동 승리** — 거머리·구조대를 쓰면 두 사람이 같은 순위로 함께 이깁니다.

### 4. 화면을 새로 그렸습니다
보내 주신 화면을 기초로, 종이에 그린 듯한 담백한 디자인으로 바꿨습니다.
밝은 회백색 바탕, 검은 외곽선, 둥근 카드, 색 원형 말, 왼쪽·오른쪽 플레이어 패널과
가운데 윷판, 오른쪽 아래 시계, 그리고 특수 승리 알림창과 최종 순위표까지
같은 모양으로 맞췄습니다.

## 수업에서 쓰는 법

1. 선생님이 주소를 알려 줍니다.
2. 학생이 닉네임을 쓰고 **모둠에서 한 명만** 방을 만듭니다.
3. 나머지는 그 방 코드를 넣고 들어옵니다. (한 방에 2~5명)
4. 방장이 시작을 누릅니다.

**모드** — `간편 수업`은 규칙이 단순한 증강만 나옵니다(처음 할 때 추천).
`본격 증강`은 71종이 모두 나옵니다.

**말 개수** — 2개는 한 차시에 두 판, 3~4개는 한 판을 길게 할 때 좋습니다.
증강이 많아질수록 판이 길어지니, 40분 한 차시라면 **간편 수업 + 말 2개**를 권합니다.

## 선생님 관제실

시작 화면 아래 `선생님용 관제실 열기` → 교사 PIN.

- **엑셀 양식 내려받기** — 문제를 채울 빈 양식
- **＋ 새 문제 세트** — 엑셀을 올리면 그 세트만의 주소가 생깁니다
- **지금 적용** — 켜 둔 세트는 학생이 기본 주소로 들어와 방을 만들어도 적용됩니다
- **관전 · 일시정지** — 모둠별 진행 상황을 봅니다

## 인터넷에 올리기 (Render)

2차 버전과 같습니다. `render.yaml`이 들어 있으니 GitHub 저장소에 올린 뒤
Render에서 Blueprint로 연결하면 됩니다.

> **교사 PIN은 반드시 Render 환경변수 `TEACHER_PIN`으로 넣으세요.**
> 코드에 적힌 기본값 `2468`은 인터넷에 올리기 전에 꼭 바꿔야 합니다.

## 직접 돌려 보기

```bash
npm install
npm start                       # http://localhost:3000
node test/play.mjs 3 full 3     # 4명이 자동으로 3판 둔다
python3 test/shots.py           # 화면을 그림으로 저장한다
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `game.js` | 윷판·이동·확률 등 순수 규칙 (화면·통신 없음) |
| `augments.js` | 증강 71종의 이름·설명·희귀도·단계 |
| `effects.js` | 증강 71종의 실제 효과 |
| `server.js` | 방·턴·채점·문제은행·교사 관제실 |
| `public/` | 화면 (index.html · style.css · app.js) |
| `test/` | 자동 대국과 화면 촬영 |

## 확인한 것

- 윷 확률 40만 번 — 전통 윷과 일치
- 증강 71종을 하나씩 발동 — 오류 없음
- 4명 자동 대국 여러 판 — 68종이 실제 선택창에 등장, 특수 승리·공동 승리·탈락 모두 작동
- 실제 브라우저 3대로 시작부터 진행까지 — 자바스크립트 오류 없음
